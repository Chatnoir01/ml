# Conditional prospective first-fork causal experiment — technical design ONLY (2026-11-07)

**Status: NOT PREREGISTERED FOR EXECUTION, NOT AUTHORIZED.** This document is an engineering design envelope inspired by Phase2H-FORK1/FORK2 archived observations; it freezes **no new scientific arm, seed, test threshold, or model budget**. It does NOT circumvent `src/adversarial_sbox/phase2i_gate.py` or the governing `research/PHASE2I_DESIGN_ENVELOPE.md`. No scientific code or new model fitting is authorized by this document.

## Confirmed identification and remaining gap

The original g5 A/F B1 groups and previously classically selected sets are identical for all nine Phase2G seeds, but the after-score member sets diverge. Across 101 comparable scored historical contexts, the exact frozen selection operator yields 12 different member sets; swapping ONLY native A/F candidate-score assignments reproduces all 12 opposite-arm decisions, **including 9/9 first g5 shortlists, 31 members per arm**. This identifies the local deterministic *selection operator* effect.

The original September model weights (only state hashes and receipts survived), the full shared RNG internal state at g5 and unexecuted counterfactual proposals did not survive. A retrospective 15-generation continuation is therefore NOT recoverable. A prospective new experiment is required to identify whether the **first-fork decision** affects **terminal neural robustness**, *not* simply the classical tuple of chosen members.

## Two possible scientific routes, never conflate

**Route 2I:** Only if a frozen Phase2H result supports **exactly one** H1/H2/H3/H4 mechanism, invoke the existing mechanism-to-intervention selector and complete the four-arm C/F/A2/S2, freshly seeded, preregistered Phase2I protocol. Current H3 observations do NOT satisfy this requirement. The H3 family, if selected, must be `bounded_neural_influence`; it cannot silently become replay, slow target or retention because rank turnover was visually striking. If none or multiple are supported, Phase2I remains blocked.

**Separate fork-causality route (a distinct future registration, not a substitute for 2I):** A single isolated g5 first-selection intervention answers whether changing **only this one score-order policy** has a terminal effect under a common subsequent policy. A positive result would be a new experimental mechanism effect, not the causal explanation of the original September terminal gap. This route requires its own new phase, standalone hypotheses, independent seed reservation, lock and authorization. It may not use Phase2I's reserved identity or its sealed holdout.

## Proposed minimal fork experiment (not yet executable)

1. For each newly preregistered fresh evolution seed, run **one** heldout-blind common history from generation 0 to the frozen state immediately before generation 5 shortlist. Retain a complete, serialized original-population, evaluated classical-cache, proposal-history and Python RNG-state snapshot. Confirm the two arms are **bitwise identical before treatment**, including actual checkpoint0 model-state bytes (not arm-tagged receipt SHA).
2. On this identical g5 state, train one fresh 16-model checkpoint bundle on the *initial frozen* 20-S-box curriculum (F policy) and another fresh 16-model bundle on the *actual current* 20-S-box curriculum (adaptive policy). Same checkpoint, model seeds, data seeds, architecture, learning budget and compute environment; verify 16 model-state SHA and candidate-scoring receipts. Model training order is a predeclared matched/balanced allocation; detect CPU/BLAS dispatch drift or stop.
3. Obtain candidate-specific scores for **exactly the same original B1 candidate set** for both models using identical frozen Q scoring seeds. Restore the same g5 predecessor snapshot in both arms, then apply native B1 sorter exactly once at the g5 shortlist with either adaptive or fixed score map. All hard classical cutoffs and protected radii unchanged.
4. Immediately after this single fork, return BOTH branches to a **common fixed-curriculum checkpoint-scoring policy** for all later shortlist/survival events. Do not swap additional adaptive score vectors; freeze g5 survival rule and g10/g15 retraining/score identity in advance. Maintain cloned exogenous RNG state at the moment of fork; candidate proposals need NOT be identical downstream when parent sets differ (this divergence is a legitimate mediated effect, not a reason to force matched proposals).
5. Advance both actual GA branches through generation 20. Count any seed with no g5 membership change as an **intention-to-treat** zero-switch unit; do not drop it after seeing results. Freeze BOTH terminals and all classical evidence BEFORE opening any distinct prospective terminal heldout evaluation. Use only new preregistered validation T/M seed blocks physically isolated from Phase2G H and Phase2U.
6. Primary paired estimand for such a future experiment: `E[Y_i(adaptive_score_at_g5) - Y_i(fixed_score_at_g5)]`, where `Y` is the already chosen frozen **terminal candidate-specific neural advantage**, lower-is-better. Choose exact paired inferential rule, CI, a practically relevant minimum effect, classical admissibility/non-degradation co-gates, all null-outcome handling and power justification **before** any new training. No a-posteriori switch to A-versus-C or best-seed analysis.

## Technical feasibility and accounting (not an execution allocation)

At the original 16 checkpoint models per bundle, sharing the frozen fixed model bundles between two forks would require **16 checkpoint0 F + 16 g5 F + 16 g5 adaptive + 16 g10 F + 16 g15 F = 80 full NN checkpoint fittings per evolution seed**. If the later prospective heldout procedure copies the original 16 candidate-specific NN trainings per terminal, add **32** frozen terminal-validation fittings per evolution seed, for **112 NN fittings per seed** (excluding synthetic smoke tests, recalculation failures and any additional controls/replications). A genuine Phase2I trial with C/F/A2/S2 would have a different, separately costed budget; these two-arm calculations cannot be passed off as its mandatory controls.

Execution must be sequential on a 16 GB host (one train job, release memory, verify CPU/BLAS, no 16-model concurrent loading by default), with explicit disk/memory/runtime profiling, execution checkpoints, complete raw model state preservation, and native root original model weight SHA receipts to eliminate the Phase2G raw-state provenance gap.

## Nonnegotiable stop rules and no claim leakage

No new evolution-seed identities may be read/generated for the scientific experiment before the independent protocol/authorization boundary. No Phase2G historical evolution seeds, Q/T/M seeds, H dataset/model seeds, or sealed 96 Phase2U neural jobs can be reused; verify the entire existing registry. No new prospective training before final Phase2H freeze/authorized separate protocol and clean CI. A two-arm fork result would answer a narrow *first-selection intervention* question only; independent Phase2J replication is still required before any general claim.

The original Phase2G verdict remains **`phase2g_adaptive_coevolution_not_supported`**. Nothing in this design document constitutes a reportable causal result, cryptographic discovery or security certification.
