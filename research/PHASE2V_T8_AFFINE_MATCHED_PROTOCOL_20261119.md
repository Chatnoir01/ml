# Phase 2V–T8: metric-matched affine S-Box variations vs ToySPN classical distinguishability

Date 2026-11-19. **Prospective preregistration: this document must be committed to GitHub before any T8 candidate S-Box, panel ciphertext, AUC, or proposed group correlation is generated or inspected.** Frozen predecessor for source-only implementation: repository `main` SHA `b03da1d95e98709869d007571de4f8bbce234a1b`. The 2026-11-19 T7 result and Phase 2A-T/U2 motivated the *question* but contribute NO measurement, candidate, key, or sample to T8. Entire Phase2U sealed 96-neural-run protocol remains untouched.

## Scientific question and limits
Can variations of the *same* AES reference S-Box under restricted affine transformations—chosen to **preserve** its global differential uniformity, nonlinearity, maximum linear correlation, algebraic degree and aggregate SAC score—produce a **reproducible between-S-Box variation** in a fixed, simple, classical ciphertext-only pair distinguisher for 4-round educational ToySPN? This tests a necessary classical structural control before any independent neural model experiment. Every box belongs to **ONE affine equivalence orbit of AES**, not 72 independent cryptographic families. No security or neural originality claim.

## Immutable source construction
- Exactly 12 **new** group labels `904011, 904058, 904105, 904152, 904199, 904246, 904293, 904340, 904387, 904434, 904481, 904528`. Each group has exactly 6 indexed candidate boxes (index 0..5): **72** S-Boxes total. No candidate selection based on output.
- Source reference `src/adversarial_sbox/references.py::AES_SBOX`, immutable `main` as above. For each (group, index), derive `random.Random(int.from_bytes(SHA256(ascii("phase2v-t8-affine-v1|GROUP|INDEX")),"big"))`. Independently shuffle two copies of `list(range(8))`: input bit permutation `pin` and output bit permutation `pout`. Then read `a = rng.getrandbits(8)` and `b = rng.getrandbits(8)`. Define `P_p(x) = Σ_{i=0}^7 (((x>>i)&1) << p[i])`; candidate `S'(x) = P_pout(AES_SBOX[P_pin(x) XOR a]) XOR b`. Each candidate is a byte permutation. Exact duplicate SHA256 boxes or nonbijective boxes -> **INVALID entire T8 study, no adaptive replacement**.
- Exact *global metric gate* for all 72 boxes: `differential_uniformity(S') == DU(AES)`, `nonlinearity(S') == NL(AES)`, `max_linear_correlation(S') == maxLAT(AES)`, `algebraic_degree(S') == degree(AES)`, `sac_score(S') == SAC(AES)`, using source `cryptoshield` functions with independent mathematical invariance rationale; verify all 72 at runtime (no skipped metrics). Invariance of the four primary metrics under affine input/output permutations is known prior art; bit *permutations* also preserve the average SAC score. **Do not require identical complete DDT/LAT matrices, which are relabelled by the transformations.**
- The cipher is exact original `src/adversarial_sbox/spn.py::ToySPN`: round key XOR, byte substitution, 11-bit rotate-left between rounds, final XOR. Rounds = **4 and 5**; 4-round keys are prefix of the same six-word sequence. Confirm independent implementation parity on 8 frozen publicly-derived test vectors. No modifications to the cipher or S-Box metric source.

## Key, input and control panel
- Exactly 2 key arms `K0`, `K1`, shared across all six S-Boxes **within each group** to control key confounding. Per (group, arm), derive six 32-bit public key words `int.from_bytes(SHA256(ascii("phase2v-t8-key-v1|GROUP|ARM|WORD_INDEX"))[:4],"big")`, WORD_INDEX 0..5. **24 unique** 6-word key schedules; keys not secrets.
- Exactly two fixed input differences `0x00000001`, `0x00000100`; no multibyte differences and no exploratory choice after outputs.
- Exactly **two independent plaintext-pair schedules** (replicates A and B) per (group, delta), **48 schedules**. Each uses `random.Random(int.from_bytes(SHA256(ascii("phase2v-t8-pairs-v1|GROUP|DELTA|REPLICATE")),"big"))`. Positive: 128 pairs `(p,p XOR delta)`. Negative: 128 `(p,q)` with `p!=q` and `p XOR q != delta`. Candidates drawn with `getrandbits(32)`, reject any plaintext block already used within that schedule (across classes), 50,000-draw max, abort on exhaustion. **The same 256 labeled pairs** are reused across all six boxes and both key arms and rounds within that group/delta/replicate, by deliberate *matched design*. Fresh replicate B pairs are disjoint from replicate A within the same (group,delta) -> check and abort on overlap (do not regenerate post outcome). Distinct source schedules must hash distinctly. Each key/round test uses a fresh deterministic null label shuffle domain-separated by group, box, arm, delta, replicate, rounds.
- Total **12 groups × 6 boxes × 2 keys × 2 deltas × 2 independent replicates × 2 depths = 1,152** prespecified panels, each 128 positive +128 negative. AUC = exact tie-aware Mann–Whitney score of `number of zero bytes in ciphertext XOR` (0 to 4), **larger score is positive**, using exact score-frequency calculation; independent check by direct 128×128 positive-negative pair enumeration. Control AUC uses shuffled labels, NOT fitted training. No neural training, no held-out Phase2U data, no use of past empirical candidate outcomes.

## Primary endpoint fixed BEFORE T8 outcomes
For each group and candidate, compute `mean_R4_AUC(rep)` over the **four cells** `K0/K1 × delta1/delta256` for replicate A and independently B. Compute **Spearman correlation with midranks** between the six candidate mean R4 AUCs in replicate A vs B, *within each group*. Exactly 12 group correlations (not 72 independent trials, not 1,152 IID cells), ties retained with averaged ranks; constant ranks -> group correlation 0. The registered **positive-direction decision** is supported only if:
1. at least **10/12** group replicate correlations are strictly positive;
2. the median of the 12 correlations is **>= 0.50**;
3. across all 1,152 shuffled-label control panels, mean null AUC is in **[0.47,0.53]**;
4. all 72 full classical-metric gates and all source/cipher/integrity controls pass.
Otherwise mark **NOT SUPPORTED** (or INVALID on hard integrity gate), never reselect subsets, candidate transforms, differences, endpoint or threshold. An observed positive result establishes *replicate-stable toy distinguisher variability within one affine orbit under the tested keys*—not independent neural prediction, an AES weakness, or a novel cryptographic theorem.
