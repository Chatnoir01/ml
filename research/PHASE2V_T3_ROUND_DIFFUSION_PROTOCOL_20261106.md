# Phase 2V-T3 — Registered round-count × byte diffusion ablation, with matched ideal-permutation control
**Registered 2026-11-06 BEFORE running any T3 AUC computation. Experimental work is source-reconstructed, standard-library only, no neural training or Phase 2U unblinding. DRAFT stacked on #172.**

## Scientific test and interpretation boundary

Prior T1/T2 found ciphertext-only classical XOR-byte distinguishers of the educational 32-bit ToySPN have AUC around 0.69 after four rounds with fixed 11-bit rotations, while matched sampled ideal 32-bit permutations are near chance. We test whether that signal survives increasing the number of rounds and whether **changing the diffusion layer** (the between-round rotate-left-11 primitive) alters it. This is a mechanistic **toy-cipher ablation**, not a general block-cipher security assessment or cryptographic novel discovery.

## Exactly registered source panel, interventions and budget

- Exactly **18** *source-reconstructed* checkpoint-zero cells: all nine original evolution seeds 726011,726023,726037,726049,726061,726073,726087,726099,726113 × two registered input XOR differences 1,256 × **one** original T-seed **776003** (original first T seed). No post-result seed selection or extra input-difference sweep.
- Each cell's 20 original 256-byte S-Boxes are sorted by SHA3-256 fingerprint, reconstructed from the **2026-09 source seed algorithm** and checked against original archived curriculum/initial-population SHA records. The **first 15** S-Boxes are the only training domain; last **five** are held-out S-Boxes. Every S-Box uses original `random.Random(776003)` plaintext pair schedule and exactly original 400 pairs / 280 train, 60 validation, 60 test. **Original `train+validation+test` SHA3** of each original 4-round/rotate-11 full cell must equal earlier frozen checkpoint-zero source reconstruction. Validation is not used for fitting.
- Exactly eight fixed ToySPN regimes: **round counts (2,3,4,5)** × **rotation between rounds (0,11)**. Rotation 11 is the original byte-mixing layer; rotation 0 deliberately eliminates cross-byte mixing and is an *artificial weakened control*. For each R, use original historical public round keys `ROUND_KEYS[:R+1]` from the 6 original key words: `(243f6a88,85a308d3,13198a2e,03707344,a4093822,299f31d0)`. This matches original four-round source ToySPN *exactly* for (R=4, rotate=11). Do not optimize number of rounds, rotations or keys after seeing outcomes. The fixed round-key prefix changes across regimes; because keys are public and the cipher is toy, effects cannot be attributed solely to rounds independent of all key context. The final whitening key position changes as prescribed by the same prefix scheme.
- Train one ordinary **Laplace-1 naive Bayes XOR-byte count table** per (cell,regime) on ONLY 15×280 = **4,200 original-key, seen-S-Box training pairs**. Test unchanged score on **900 seen** and **300 held-out S-Box** test ciphertext pairs. Also score fixed-sign negative XOR Hamming weight, positive zero-XOR-byte count, and exact constant null. All test labels held out until AUC evaluation. All ROC AUC tie-aware, no post-hoc score sign reversal.
- For each of the 18 source cells, simulate exactly one ideal 32-bit **lazy bijective permutation per S-Box fingerprint/evolution seed**, reusing the same map for both differences and no round-count-dependent refitting. Exactly **180** persistent random-permutation oracles with `random.Random` seeds defined as `int.from_bytes(SHA256(b"phase2v-t3-ideal-prp-v1|" + evolution_seed_ascii + b"|" + sbox_fingerprint_ascii),"big")`; sparse Fisher–Yates without replacement over 2^32 output labels and cached input→output. Query in strict order evolution ascending, difference (1,256), 20 SHA3-sorted S-Boxes, then each plaintext pair in original train→validation→test order, left then right. Fit the same histogram independently on 4,200 ideal-control train pairs and test on 900/300 same-label pairs; null/hamming/zero-byte scores also reported. **This is ONE sampled ideal-permutation control**, not a theorem over all 2^32! permutations.
- Fixed number of paired test panels: **18×8×2 = 288 ToySPN regime/seen-status rows**, plus **18×2 = 36** once-per-cell ideal PRP control rows, each with exactly 4 scores and 3 source provenance digests. These 324 panel rows are dependent (same curricula, plaintext draws and keys); no IID confidence intervals, p-values or sample-size power claims.

## Hard validation and provenance gates

1. Verify **all nine** reconstructed curriculum SHA, **all 180** S-Box fingerprints and the 18 source cell split SHA from the original checkpoint-zero reconstruction report, and the complete original 4-round/rotate-11 source generator for every S-Box. Also compare the resulting (R=4, rotation=11) seen/unseen XOR/Hamming/zero-byte and histogram test AUC **exactly** with the corresponding 36 prior T1 rows for original source keys, difference 1/256 and T 776003.
2. Test new encryption implementation against ORIGINAL `ToySPN` for R=2,3,4,5 under rotation 11 on small fixed source values and against fixed algorithmic loop for rotation 0; independent decryption/roundtrip on 256 known plaintexts per regime/S-Box (small sample, not proof of security). Validate sparse Fisher-Yates 8-bit toy full-domain permutation is a bijection, 180 sampled oracles are injective for all queried inputs and repeated inputs map identically.
3. For every cell and test panel, require original plaintext labels and split geometry, exact ciphertext/pair disjointness between training and testing *within the corresponding family*; bail out if a panel fails rather than cherry-picking.
4. Output all 288 ToySPN rows plus 36 ideal rows, each with source SHA, input difference, evolution seed, T seed, rounds, rotate, seen/held-out label, counts and exact AUC values. Strict group-total assertions; canonical self-hashed JSON with full per-regime/per-class medians and min/max; CSV with stable field ordering.
5. Report sign and size of AUC contrasts **per cell**: original rotation-11 R2→R3→R4→R5 and rotation 0 vs 11 at fixed R. **Do not assert monotonically falling** discrimination without actual series. Check no numerical advantage is attributed to a neural network (none is fitted).
6. Do not run a new neural fit or score the prospective sealed Phase2U panel. Keep historical Phase2G `phase2g_adaptive_coevolution_not_supported` frozen.

## Registered primary and secondary outcomes

**Primary:** across nine original evolution seeds, two input differences and each of the **seen** and **held-out-S-Box** panels, summarize the AUC change between 2 and 5 original rotate-11 rounds for the fitted histogram, including all 18 paired cell changes separately. Report R4 result as an exact T1 source replication. Compare fixed R4 rotate-11 histogram AUC to the (single-draw) ideal PRP AUC within each original cell, separately for seen and heldout.

**Secondary:** compare no-between-round-rotation R=0 vs original rotation 11 at all four prechosen R values and both seen statuses, and report Hamming / zero-byte baselines. Compute per-S-Box differential-uniformity (max DDT count over nonzero input difference) for the original 180 permutation S-Boxes. Report per-evolution-curriculum median DDT uniformity; any correlation with the AUC effects is exploratory descriptive on **nine correlated groups**, not a new prediction law or p-value.

**Potential outcomes:** strong signal at rotation 0 confirms byte-separability of the deliberately weakened toy structure; a lower histogram AUC at 5 than at 2 rounds on rotation 11 would be consistent with better diffusion, but neither outcome is guaranteed a priori. No claim of real-world cryptographic security, novelty, standard PRP distinguishing advantage, or universal generalization is authorized.
