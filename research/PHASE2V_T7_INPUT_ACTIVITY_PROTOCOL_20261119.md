# Phase 2V–T7 — prospective input-difference activity experiment
Date: 2026-11-19. **Protocol frozen before any T7 S-Box generation, cipher observations, AUC calculations or result inspection.** This research branch is isolated from the stacked Phase2V T1–T6 history. **No neural fitting, no sealed Phase2U outcomes, no modifications of original studies and no security claim.**

## Question and rationale
T6 found ToySPN 4-round vs 5-round separation by a simple ciphertext-pair histogram (unseen S-Boxes median AUC about 0.686 vs 0.552), but a full-DDT/two-round active-byte scalar failed its prospective out-of-group prediction criterion. T7 asks a more modest **structural** question: does the *input XOR difference's number of active bytes* modify the predictive power of a fixed, untrained count of zero output-XOR bytes? T7 is NOT a replication of T6's trained four-position histogram and does NOT explain historical Phase2G terminal neural performance.

## Frozen source, cohorts and data generator
- Source primitive: current main SHA `b03da1d95e98709869d007571de4f8bbce234a1b`, `src/adversarial_sbox/spn.py::ToySPN`: 32-bit bijective four-byte SPN; round-key XOR, bytewise fixed bijective S-Box, rotate-left 11 **between** rounds, terminal key XOR; evaluate **4 and 5 rounds** with 5-word / 6-word prefixes of one common key schedule.
- Exactly 12 previously unused new evolution-group labels: `903011, 903048, 903085, 903122, 903159, 903196, 903233, 903270, 903307, 903344, 903381, 903418`; each group has exactly **8** independent `random.Random(sha256_int("phase2v-t7-sbox-v1|GROUP|INDEX"))` shuffles of `range(256)`, INDEX 0..7; do not choose or discard boxes after examining outputs. Every 256-entry box must be bijective; across groups all 96 SHA256 box fingerprints must be distinct.
- Exactly four registered differences: `0x00000001` (one active byte, low), `0x00000100` (one active byte, next), `0x00010100` (two active bytes), `0x01010101` (four active bytes).
- For each of 96 boxes derive exactly six public 32-bit key words `int.from_bytes(SHA256("phase2v-t7-key-v1|GROUP|BOX_SHA256|WORD_INDEX")[:4],"big")`, WORD_INDEX=0..5. Keys are deterministic research inputs, **not production secrets**.
- For each (GROUP, BOX_SHA256, DIFFERENCE) create 128 labeled **positive** plaintext pairs `(p,p XOR difference)` and 128 **negative** pairs `(p,q)` with `q!=p` and `q != p XOR difference`; sample with `random.Random(sha256_int("phase2v-t7-pairs-v1|GROUP|BOX_SHA256|DIFFERENCE"))` using `getrandbits(32)`. Reject/retry candidate draws if *either 32-bit plaintext block* was used previously in this panel, including across classes. Reject on exhausted fixed budget of 50,000 candidate draws per panel. Reuse these **exact plaintext pairs** for both 4 and 5 rounds (paired design), no train/validation fitting, no outcome-driven filtering.
- Panel unit = one group, box, input difference and rounds: `12 × 8 × 4 × 2 = 768` panels with 128 positive and 128 negative observations each, no unregistered panel exclusions. Source independent from T6 groups, public keys and sampled plaintext pairs.

## Locked metrics and comparisons
- For each ciphertext pair, score `S = count of zero bytes in C0 XOR C1`, a fixed integer 0..4, with **larger S = more likely positive**. This score was selected from T6 controls **before generating any T7 data**, not fitted to T7 labels.
- Per-panel exact tie-aware AUC: enumerate score-class counts (0..4) and compute `sum_{s,t} pos[s]*neg[t]*(1[s>t]+0.5*1[s=t])/(128*128)`. Also report rate with at least one zero XOR byte separately for positive and negative classes.
- Fixed negative control: shuffle exactly 128 positive and 128 negative labels over the 256 unchanged scored observations using independently derived `random.Random(sha256_int("phase2v-t7-null-v1|GROUP|BOX_SHA256|DIFFERENCE|ROUNDS"))`; calculate the same AUC. No model fitting or inspection-based switching.
- Group unit of analysis: **12** independent labels, NOT 768 independent samples. For each group, round, difference, mean AUC over the 8 boxes. Main contrast at round 4: `D_g = ((AUC_g,4,0x1 + AUC_g,4,0x100)/2) - AUC_g,4,0x01010101`. Prespecified directional success only if **at least 10 of 12** group contrasts are strictly positive **AND** group median contrast is **>= 0.05**, with no skipped group or sign reversal. Otherwise hypothesis NOT SUPPORTED. Null quality gate: across all 768 panels, mean shuffled-label AUC within [0.47,0.53]; failure invalidates conclusions, not fixed by new seeds.
- Secondary, reported regardless of main result: R5 same 1-byte-vs-4-byte contrast, R4 and R5 2-byte AUC, R4→R5 paired AUC difference by each delta, full 12 group values, all 768 per-panel values, source fingerprints. No formal p-values or neural superiority claim; small clustered N and synthetic toy cipher.

- A second independent implementation of the discrete tie-aware AUC must agree on prespecified edge panels, and a second unchanged full run must reproduce canonical JSON byte-for-byte (SHA256 recorded); an intentional tamper/invariant negative control must fail.
- Never tune seeds, differences, score direction, eligibility, endpoints or thresholds after seeing T7 outputs. Retain negative or null results. No mutation of historical experimental states and no automatic merging or production usage.

## Interpretation
A positive T7 result would establish *only* a new descriptive controlled differential activity effect for this 32-bit ToySPN at these preselected deltas under this fixed classical score. It is neither a proof of cipher weakness in AES/real-world schemes nor proof of S-Box improvement, cryptographic originality, neural gains, forward secrecy or post-quantum security. Independent fresh-cohort replication is required before generalization.
